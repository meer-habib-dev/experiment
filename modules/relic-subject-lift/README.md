# Relic Subject Lift module

Local Apple Expo module for the [Relic Lift](../../src/features/relic-lift/README.md) experiment. It
uses Apple Vision for foreground extraction and renders the isolated subject through a Metal-backed
native view.

This module is not published independently. It is autolinked from `modules/` and requires a new iOS
development build after Swift, podspec, or module configuration changes.
